СНИМОК by mysik
===============

Скриншоты в два движения: нажал PrintScreen, выделил область — снимок
уже в буфере, можно вставлять в Telegram, Discord или документ.

Что умеет
---------
• PrintScreen — снимок области, Ctrl+PrintScreen — весь экран.
  Ещё можно щёлкнуть по значку в трее или нажать кнопку в окне.
• «Через 3 секунды» — успеешь открыть меню или подсказку.
• Редактор:
  ↗ стрелки, ▢ рамки, ▬ маркер, T текст,
  ▦ размытие (спрятать номер карты, переписку, лица),
  ① номера по порядку — удобно для инструкций.
  6 цветов, отмена по Ctrl+Z.
• Ctrl+C — скопировать, Ctrl+S — сохранить, Ctrl+Shift+S — сохранить как
  (PNG или JPG).
• Последние снимки видны прямо в окне, их можно открыть и дорисовать.
  Все снимки лежат в «Изображения\Снимки by mysik».


Сборка и запуск
---------------
1. Распакуй архив и проверь, что все файлы лежат рядом
   (Snimok.cs, Shell.cs, MainWindow.xaml, Theme.xaml, app.ico,
   app.manifest). Запусти build.bat.
2. Запусти Snimok.exe. Права администратора не нужны.
3. Включи «Запускать вместе с Windows» — программа будет ждать в трее.

Если PrintScreen открывает встроенную «Ножницы» Windows 11, выключи
в Параметрах → Специальные возможности → Клавиатура пункт
«Использовать клавишу Print Screen для открытия функции захвата экрана».
