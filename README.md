# Снимок by mysik

Скриншоты в два движения: нажали PrintScreen, выделили область — снимок уже в буфере, можно вставлять в Telegram, Discord или документ.

**Страница программы и скачивание:** https://mysik-portfolio.vercel.app/soft/snimok.html

## Что умеет

- **PrintScreen** — снимок области, Ctrl+PrintScreen — весь экран.
- **Через 3 секунды** — успеете открыть меню или всплывающую подсказку.
- **Редактор** — стрелки, рамки, маркер, текст и 6 цветов. Отмена по Ctrl+Z.
- **Размытие** — спрятать номер карты, переписку или лица.
- **Нумерация ①②③** — удобно для инструкций.
- **История снимков** — последние снимки прямо в окне, их можно открыть и дорисовать.

## Как начать

Нужна только Windows 10 или 11 — компилятор .NET Framework 4.x уже встроен в систему.

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP**, и распакуйте.
2. Запустите `build.bat` — через пару секунд рядом появится `Snimok.exe`.
3. Откройте `Snimok.exe`. Права администратора не нужны.
4. **Включите «Запускать вместе с Windows».** Программа будет ждать в трее.
5. **Нажмите PrintScreen.** Выделите область, Ctrl+C — скопировать, Ctrl+S — сохранить в PNG или JPG.

## Полезно знать

- PrintScreen открывает «Ножницы» Windows 11 — выключите в Параметрах → Специальные возможности → Клавиатура пункт «Использовать клавишу Print Screen для открытия функции захвата экрана».
